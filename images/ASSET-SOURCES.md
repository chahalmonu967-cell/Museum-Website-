# Artwork image sources

The project uses the original artwork image files rather than crops taken from the submitted screenshots.

1. **Birmingham / Congreve Street** — Birmingham Museums Trust image published on Unsplash: https://unsplash.com/photos/painting-of-village-DdJ1j6liIfE
2. **A Woman Slicing Bread** — Johannes Christiaan Janson, Rijksmuseum SK-C-156, public-domain image on Wikimedia Commons: https://commons.wikimedia.org/wiki/File:Een_vrouw_die_brood_snijdt_Rijksmuseum_SK-C-156.jpeg
3. **Portrait of Maritge Claesdr Vooght** — Frans Hals, Rijksmuseum SK-C-139, public-domain image on Wikimedia Commons: https://commons.wikimedia.org/wiki/File:Portrait_of_Maritge_Claesdr._Voogt_(1577-1644)_by_Frans_Hals_027.jpg
4. **Portrait of a Man** — Rijksmuseum SK-C-1553, public-domain image on Wikimedia Commons: https://commons.wikimedia.org/wiki/File:Portret_van_een_man_Rijksmuseum_SK-C-1553.jpeg

The HTML loads these source images from their hosted image URLs, so an internet connection is required for the artwork to appear. If you want the site to work completely offline, download the original files from the source pages and save them in this folder, then change the HTML image `src` attributes to the matching local filenames.
